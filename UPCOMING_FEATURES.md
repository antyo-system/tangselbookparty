# Tangsel Book Party — Project Roadmap & Feature Checklist

This document tracks the phased rollout of features for the **Tangsel Book Party** community library platform.

---

## 🎯 Phase 1: Essential User Web (Current Release)
Focus: Extremely clean, fast, and intuitive user catalog & borrowing experience.

- [x] **Clean Essential Book Cards**: Cover, Status badge (`Available` / `Borrowed`), Title, Author, Genre & Rating.
- [x] **Quick Search & Category Filters**: Search by Title/Author/Genre/ISBN; filter by category & availability.
- [x] **Simplified Book Detail Modal**: Synopsis, shelf location, book owner, community reviews, and borrow trigger.
- [x] **Borrowing Duration Selector**: 7, 14, 21-day options with handover method choice (In-Person Meetup vs Courier).
- [x] **Reservation Queue**: Queue position & estimated return date math when a book is borrowed.
- [x] **Member Profile**: Active borrows, queue reservations, borrow history, and wishlist.
- [x] **Clean Role-Based Navigation**: Admin Panel button strictly hidden for regular members.

---

## 🚀 Phase 2: Advanced Reader Experience (Upcoming)
These features are queued for future iteration to keep the initial UI lightweight:

- [ ] **Goodreads Rating Breakdown**: 5-star to 1-star visual percentage bars in book detail modal.
- [ ] **Kindle Reading Speed Estimator**: Estimated reading time (e.g., `~5.2h Read`) based on page count.
- [ ] **"Why Read This Book?" (Why Opsi)**: AI/Community recommendation box with 3 key takeaways.
- [ ] **Google Play Books Sample Chapter Reader**: Interactive 1st chapter excerpt previewer.
- [ ] **Community Reading Challenge Banner**: Annual goal tracker (e.g. `420 / 500 Books Read`).

---

## 🛡️ Phase 3: Separate Admin Application / Portal (Upcoming)
- [ ] **Dedicated Admin App**: Separate admin repository/dashboard with staff auth login.
- [ ] **Hardware QR Scanner Integration**: Native bluetooth/USB barcode reader support for event check-in desks.
- [ ] **Automated WhatsApp Business Bot**: Direct API integration for sending H-2 due date reminders.
